# Frontend Developer Guide

## 1. `index.html`
The main dashboard structure. It contains:
- Header
- Sidebar
- Dashboard
- 8 project modules
- Links to Sign In / Sign Up

## 2. `css/style.css`
All visual styling is here:
- Colors
- Spacing
- Cards
- Map UI
- Responsive layout
- Hover/bubble animation
- Sign In/Sign Up styling

## 3. `js/app.js`
All frontend interactions are here:
- Module navigation
- Search
- Toast messages
- SOS confirmation
- Theme preview
- Hover micro-interactions

## 4. `pages/`
Each page is separated so it can later be connected to the Spring Boot backend.

## How to run
Open `index.html` with VS Code Live Server.

## Next development stage
Replace the demo/static values with:
React components (if the project is migrated to React),
Spring Boot REST APIs,
PostgreSQL data,
FastAPI ML predictions,
Maps/Weather/Traffic APIs.
